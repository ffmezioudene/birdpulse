# Runtime dependencies. Everything here is on public PyPI — no private
# package indexes required. Plain `pip install -r requirements.txt` works
# on Railway, Render, Fly, Heroku, or any vanilla Python 3.11 image.
#
# Audit (what each one is actually used for):
#   fastapi           — web framework
#   uvicorn           — ASGI server (Dockerfile CMD)
#   python-dotenv     — load backend/.env in local dev
#   motor             — async MongoDB driver
#   pydantic          — request/response models
#   python-multipart  — required by FastAPI for any multipart/form-data
#   httpx             — Wikipedia / Xeno-canto / Modal Perch outbound calls
#   openai            — OpenAI SDK used by llm_shim.py (Photo ID, enrich, chat)
#
# Dev-only tooling (pytest, black, isort, flake8, mypy) lives in
# requirements-dev.txt and is NOT installed in the production image.
